### 2. New Notebook: `notebooks/models/10_ZeroShot_CloudLLMs.ipynb`

Zero-shot classification using 3 free cloud LLMs via the [OpenRouter](https://openrouter.ai) API.

**Models:**

| Key | Model | Size | Type |
|-----|-------|------|------|
| `deepseek` | DeepSeek V4 Flash (`deepseek/deepseek-v4-flash:free`) | 284B MoE | Cloud, free |
| `qwen` | Qwen3 80B Instruct (`qwen/qwen3-next-80b-a3b-instruct:free`) | 80B | Cloud, free |
| `llama33` | Llama 3.3 70B (`meta-llama/llama-3.3-70b-instruct:free`) | 70B dense | Cloud, free |

**How to run:**
- Change `DATASET` and `MODEL` variables at the top of the notebook
- Run all cells
- Repeat 9 times (3 datasets x 3 models)

**Output per run:**
- `results/predictions/{DATASET}_{MODEL}_summary.csv`
- `results/predictions/{DATASET}_{MODEL}_test_predictions.csv`

**Design:**
- Same checkpoint/retry/promptbook pattern as notebook 08 (Ollama)
- Saves checkpoint every 50 tweets; resumes from checkpoint if interrupted
- JSON structured output: label + reasoning + confidence

### 4. Runner Script: `scripts/run_all_cloud.py`

Standalone Python script — runs all 9 dataset/model combos without needing a notebook.

**Usage:**
```bash
# Run all 9 combos automatically
python scripts/run_all_cloud.py

# Run a single combo
python scripts/run_all_cloud.py --dataset manchester --model deepseek
```

**Features:**
- Resume support via checkpoints — skips already-completed combos
- Prints final results table sorted by F1 at the end
